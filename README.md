# Editor de Vídeo com IA

Editor de vídeos curtos (Reels/TikTok/Shorts) com IA: legendas animadas, zoom dinâmico, B-roll, motion graphics e sound design automáticos.

- **[PLANO.md](PLANO.md)** — plano completo (arquitetura, funcionalidades, roadmap).
- **`codigo-base/`** — código de referência reaproveitado de projetos open source (MIT), separado por funcionalidade. Licenças em `codigo-base/LICENCAS/`.

Os repositórios originais completos ficam em `referencias/` (não versionado).
